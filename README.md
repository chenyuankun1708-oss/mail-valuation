## 网页数据传输

网页生成时才会读取估值表和本机数据库缓存；访客浏览器不会连接Wind、RQData或邮箱。生成结果采用轻量`index.html`、首屏`/api/page-data`和固定白名单模块接口：市场研究、多因子、底层资产、台账/标签工作簿及风控日报VaR仅在打开对应页面时下载。接口和`app.js`沿用网页Basic Auth，响应使用gzip、ETag与私有缓存；白名单之外的文件路径不能通过网页读取。当前首屏压缩传输量由原整页约14.3MB降至约1.8MB，具体大小随估值数据增长而变化。

每次网页重建都会用数据更新时间生成新的`app.js`版本参数，同时脚本响应强制校验ETag；因此功能更新后普通刷新即可获取新版，不应再短暂显示旧按钮或旧布局。

本项目只做一件事：从邮箱下载指定 17 只单一资产管理计划的估值表，读取资产净值、总份额、单位净值和累计单位净值，估算申购/赎回/分红，计算单一投资人的收益与收益率，并通过本地网页展示。

## 能否只靠估值表判断现金流

可以识别和估算，但不能保证每一种情况都能精确分类。

- 追加申购、部分赎回：相邻估值表的总份额发生变化时，可以高置信度判断方向；金额按“份额变化 × 当日单位净值”估算。若两个估值日之间发生多笔反向交易，只能看到净变化。
- 分红：累计单位净值与单位净值之间的差额扩大时，可以识别为分红候选并估算金额。若模板没有正确维护累计净值，或分红与赎回同时发生，仍需分红公告或银行流水确认。
- 收益金额：17只产品均只有一个客户，因此直接按客户持有的全部资产净值计算：`期末资产净值 - 期初资产净值 - 申购金额 + 赎回金额 + 现金分红`。
- 年化收益率：同时展示资金加权XIRR和累计单位净值CAGR。XIRR使用期初资产、台账申赎、现金分红和期末资产；净值年化收益率只使用所选区间内的真实累计单位净值。
- 风险指标：累计单位净值相邻变化按实际间隔天数换算为日对数收益，据此计算年化波动率和固定2%无风险利率的夏普率；最大回撤使用累计单位净值历史峰值到谷值的最大跌幅。收益分析指标卡同时列示期初资产、期末资产，并将最大回撤区间紧随最大回撤展示为 `YYYY-MM-DD → YYYY-MM-DD`。
- 总份额：只用于核验申赎和估值表一致性，不用于计算收益。部分模板无法可靠提取真实份额，程序可能用 `资产净值 ÷ 单位净值` 反推；反推份额会随净值波动，不代表真实申赎。
- 边界注意：若台账登记日期与估值表确认申赎的日期不一致，按月统计可能发生跨期偏差，应核对边界附近流水和估值表。
- 新成立产品：若开始日期前没有估值表，但区间内已有首次投资和期末估值，按期初资产为0计算，区间内申购从收益中扣除。

建议至少保留每个交易日或每次现金流前后的估值表。页面会展示事件依据、置信度和超过 45 天的数据间隔警告。

## 安装与配置

需要 Python 3.7+：

```powershell
python -m pip install -r requirements.txt
```

在项目根目录创建 `.env`（不要提交密码）：

```dotenv
IMAP_SERVER=mail.example.com
IMAP_PORT=993
IMAP_USER=user@example.com
IMAP_PASS=your-password

# 可选的第二个邮箱，后续可继续使用 IMAP3_* ... IMAP9_*
IMAP2_SERVER=mail.example.com
IMAP2_PORT=993
IMAP2_USER=user2@example.com
IMAP2_PASS=your-password

# Wind Oracle指数行情（真实密码只放在本机.env）
WIND_DB_USER=your-wind-user
WIND_DB_PASSWORD=your-wind-password
WIND_DB_DSN=your-oracle-service-name
```

## 使用

网页“数据与说明 → 代码指令”使用统一宽度的分组卡片，按“首次安装与分享设置、邮件与估值表、行情与专项数据、网页生成与运行、检查与测试”展示。长PowerShell命令可在命令框内自然换行；页面覆盖 `app.py` 的全部公开命令，并明确 `portfolio-var` 只能主动执行、默认 `refresh` 不会重算风控日报VaR。

把手动放入 `products/`（包括 `products/FOF/`）的估值表复制归档到标准产品目录。原始文件保留不动，附件内容按 SHA-256 去重：

```powershell
python app.py organize
```

生成可直接打开、无需启动服务的任意区间收益计算页面：

```powershell
python app.py build
```

单独更新中证1000、中证500和沪深300的Wind日线缓存：

```powershell
python app.py benchmark
```

单独更新指数VaR和IF、IC、IM四期限贴水缓存：

```powershell
python app.py risk
```

整理本地历史底层估值表并更新多因子缓存：

```powershell
python app.py underlying-mail
python app.py underlying-organize
python app.py factor
```

历史压缩包放在 `底层资产/估值表.zip`。整理命令使用本机7-Zip正确处理旧ZIP中文文件名，解压前检查路径、符号链接、文件数量和展开大小，仅归档Excel并按SHA-256去重。`factor`读取各底层产品最新估值表的A股叶子持仓，从Wind取得九类基础因子并执行截面缩尾、标准化、市值加权及行业映射。网页可在已缓存的多因子估值日期间切换；每个快照使用不晚于持仓估值日的最近Wind因子日，后续刷新自动追加新快照。网页中的“多因子分析”是自研暴露分析，不是MSCI Barra正式风险模型。

行情来自本机配置的Wind Oracle数据库，从 `AIndexEODPrices` 读取指数日收盘，从Wind股指期货行情和合约资料表读取IF、IC、IM，不再访问公网行情接口。凭据只从环境变量或被Git忽略的 `.env` 读取；指数缓存保存于 `market_data/index_daily.json`，风控缓存保存于 `market_data/risk_daily.json`。生成网页固定嵌入2010年以来的指数缓存，因此可选择早于FOF成立日期的指数比较区间。`build` 只读取本地缓存、不连接数据库；单品种失败时保留上次成功缓存。`refresh` 的顺序为邮件下载、估值表整理、指数更新、风控行情更新、网页生成，但不会重新解析风控日报或计算全资产VaR。

生成结果位于项目根目录的 `index.html`。页面可人工选择开始和结束日期，并在“项目说明”中集中展示计算口径、常用代码指令和历史改动。如果边界当天没有估值表，每只产品分别使用该日期之前最近的估值表。申购赎回明细读取根目录《专户资金台账.xlsx》的 `2024`、`2025`、`2026` 工作表；收益金额按期初/期末资产净值扣除台账净申购并加回现金分红计算。产品详情同时展示资金加权XIRR、累计净值风险指标、指数同期表现、相对中证1000的Alpha/Beta和归一化对比曲线。对比图默认勾选当前产品和三只指数，其他顶层产品默认不选，可按需勾选进行同期比较；不再重复展示单独的产品净值曲线。能解析底层持仓的FOF还展示底层产品收益率贡献柱状图，贡献率按底层期间估算收益除以FOF区间首个真实估值日资产净值计算。当前总投资额读取 `专户资金余额(2026)`，会议批准额度汇总2026流水区的审核金额，不读取下方“额度/占用”汇总区。计算口径和已知限制详见 [CALCULATION_METHOD.md](CALCULATION_METHOD.md)。

汇总表按父子层级展示：创新金融业务总部所有组（所有产品）为父级大分组，FOF1证投组、FOF2研究所组和其他组为三个缩进子组。“可计算”边界使用本地Wind白名单A股指数行情日期并集判断交易日：交易日必须有请求日当天估值，非交易日才允许向前取最近估值；日历覆盖范围外的工作日从严按交易日处理。

FOF1证投组在投资总览中采用混合穿透口径拆分：全委组合按10只顶层FOF统计，包括尊享FOF55号、元盈FOF1号、3791号、8075号、11518号、11598号、5588号、君得3640、聚智多策略9号和嘉盈1号；其余天玑13号、源泉优享FOF3号和盛乾同行2号按截止日前最近估值表穿透。“形式=专户”的在投底层归专户组合，集合、其他、未匹配及所有非专户底层归策略组合，砚博继续扣除并归其他组。同一底层跨FOF持有时按持仓分别计数。子组合金额取底层实际市值和成本，不强行分摊现金、费用及应收应付。FOF1下以二级子行展示“未穿透差额（现金及净应收应付）”，金额为FOF1期末净资产扣除全委顶层净资产、专户及策略底层市值，主要反映三只穿透FOF的现金、应收应付及费用净额；该行不计算区间收益、产品数量和投资成本。专户和策略的可计算分子还要求所属FOF满足所选区间边界，不能因底层存在历史收益数据而提前计入。

投资总览“报告出具”可输入截止日并下载Excel月报，格式与 `monthly_report/output/FOF月报_2026年07月.xlsx` 一致。报告月度起点取上月最后一个日历日，终点使用输入的实际截止日，估值边界向前取最近可用估值表。该功能由本机受密码保护的网页服务实时生成，须通过 `python app.py run` 或 `python app.py share` 使用；直接双击静态 `index.html` 无法调用生成接口。

## 数据要求与目录

估值表支持 `.xls` 和 `.xlsx`，可位于 `products/` 的任意子目录。系统仅接受配置中的 17 只产品，并按表头或文件名匹配。至少需要两张不同估值日的表才能计算收益。

核心代码：

- `valuation_app/config.py`：唯一的产品白名单与别名。
- `valuation_app/mail.py`：IMAP 附件下载与内容去重。
- `valuation_app/parser.py`：多模板估值表字段解析。
- `valuation_app/analytics.py`：事件识别、收益和收益率。
- `valuation_app/benchmark.py`：三只Wind指数的Oracle查询、本地缓存和故障回退。
- `valuation_app/web.py`：零前端依赖的本地网页。

## 底层标签与策略分析

构建网页时以只读方式解析《产品标签.xlsx》和《管理人清单.xlsx》。《管理人清单》“策略归类拆分”优先提供一级/二级标签及“专户/集合”，《产品标签》补充通用标签。简称无法唯一匹配时统一归入“其他”，可在网页“产品标签”窗口核查来源、匹配方式和状态。

“策略组合分析（全部FOF底仓）”使用匹配结果的有效一级标签汇总。管理人清单字段映射为：B列“管理人名称”→管理人、I列“所投产品名称”→底层产品、J列“所投具体策略”→分类依据、K列“投资形式”→专户/集合、CD列“一级标签”→原始一级标签、CE列“二级标签”→二级标签。《产品标签》按表头读取“管理人、产品名称、一级标签、二级标签、是否有敞口”；一级标签为空时以工作表名补充。完整优先级、匹配规则和回退口径详见 [CALCULATION_METHOD.md](CALCULATION_METHOD.md#标签来源及字段映射)。

FOF持仓明细按“一级标签 → 二级标签 → 投资形式”展示。底层区间收益仍是可比持仓估算；收益率、夏普、最大回撤、卡玛和Alpha/Beta使用估值表的市价/估值价格作为净值代理，不代表管理人正式累计单位净值。单只FOF策略组合表展示有效一级标签、期末市值、策略占比和区间可归属估算收益贡献，不再展示“占FOF期初资产”；期末市值结构环形图和收益贡献正负柱状图仅改变呈现方式，不改变计算口径。

收益分析的持仓明细中，底层产品名称可在原页面内联展开组合图：深色折线表示当前FOF和所选日期区间的估值价格代理，淡色柱表示投资金额（持仓市值）。不打开新页面，不单独绘制市值曲线。估值价格不是管理人正式净值，投资金额会同时受价格和持有份额变化影响；系统不补造缺失估值日。

原始一级标签“股票”会转换为有效一级标签：包含“中性”或“完全对冲”的为“股票中性”；包含“灵活对冲”“多空对冲”或“不完全对冲”的为“股票对冲”；其余股票多头、指数增强及缺少更细敞口说明的为“股票指增”。网页保留原始标签、有效标签和分类依据供核查。

“指数同期表现”下方的全局策略组合分析汇总所选区间内全部可计算FOF底仓。同一产品被多个FOF持有时按各持仓分别累计；砚博只随天玑13号底仓统计一次。底层估值价格代理曲线提供全选和全不选，全选包含全部底仓及其相关基准指数。一般时间序列图按真实日历日期定位；收益分析中单底层产品的内联曲线改用本地Wind A股交易日轴，压缩周末和休市日、保留缺失交易日间隔，日历覆盖不足时回退真实日历并提示。估值价格代理可能因分红除权出现机械跳变，不等同于管理人正式累计单位净值。

全局策略绝对收益率使用底层估值价格代理区间收益率，并按有有效价格序列的期末持仓市值加权：`Σ(期末市值 × 代理区间收益率) ÷ Σ期末市值`。可归属估算盈利是独立金额口径，不再通过 `期末市值－盈利` 反推投入本金。有效一级标签可折叠展开，底层持仓按净值代理区间收益率从高到低排列。策略图表支持鼠标悬浮查看标签、金额、占比和收益率。

产品持仓明细采用一级标签、二级标签合并展示的矩阵表，剔除“以公允价值计量且其变动计入当期损益的其他投资_其他投资”“私募理财产品”等会计汇总项，不展示成本列及对应基准/Alpha/Beta列；表格在产品详情区域内横向滚动，不撑宽首页布局。

网页采用FOF投资驾驶舱结构：深色左侧导航分为投资总览、收益分析、市场与基准、策略组合、风险管理、底层分析及数据与说明；持仓明细统一放在收益分析，不再设置重复的“持仓与穿透”页面，旧 `#holdings` 地址自动转入收益分析。顶部统一提供日期、分析范围、数据状态和报告入口。URL Hash保存当前模块及产品位置。顶部“需关注”及首页异常数字可点击进入“数据与说明”，按估值解析、资金台账、产品标签、指数行情和底层估值表查看逐项明细；该数字是数据完整性提示，不等同于收益错误或投资风险。Barra分析和交易归因在所需因子数据及底层交易流水接入前保持禁用，不生成替代性结果。

网页右上角的“生成报告”按当前所选日期区间生成固定模板报告，并可通过浏览器打印功能导出PDF。报告包括各组收益表现、三只指数同期表现、全部FOF底仓策略占比与收益率排名，以及每个策略净值代理收益率最好和最差的5项底层持仓。报告结论由本地JavaScript规则生成，不调用AI、不上传数据。计算口径、代码指令、历史改动、资金台账和产品标签五个入口位于网页顶部。

投资总览“报告出具”还可按具体估值日期生成并下载估值表ZIP。压缩包只包含该日实际存在的已配置顶层产品原始估值表，不使用月报的向前取值规则；附件按内容去重，同产品同日存在多个版本时保留可解析持仓更完整的一份。该下载只能通过`python app.py run`或`python app.py share`提供的Basic Auth网页使用。

报告第三章除图表和排名表外，还会按期末市值占比从高到低，用文字完整列出全部有效一级策略及各自占比，不省略占比较小的策略。

## 风控页面

网页顶部“风控页面”展示中证1000、中证500和沪深300的90%、95%、99%历史模拟一日VaR，以及IF、IC、IM当月、下月、当季、下季年化贴水曲线和贴水变化VaR。另通过RQData读取2010年以来10年期中债国债收益率曲线，按相邻日收益率变动的右尾计算90%、95%、99%不利上行VaR并以bp展示；因没有债券久期和利率风险敞口，不折算金额。指数使用2010年以来官方连续点位；IC、IM仅从实际上市日开始，不虚构历史。RQData凭据只读取环境变量或被Git忽略的`.env`中的`RQDATAC_CONF`，更新失败时保留上次成功缓存。

风控日报全资产“简化估算VaR”独立放在网页“其他管理”，与FOF底层风控分开。只有显式执行`python app.py portfolio-var`才会只读解析最新日报、重算300项资产、重建网页及Excel；默认`refresh`、`risk`和`build`只保留并展示上次成功缓存。程序默认查找`.env`中的`RISK_REPORT_PATH`，其次查找被Git忽略的`data_sources/风控日报*.xls[x]`和当前用户下载目录。17只权益FOF按日报产品本金的5%计算；国泓、长盛汇利2号和长盛海昇5号只按底层债券明细计算，避免产品层本金重复；结构化资产和信托默认固收。固收金额VaR使用代理久期、无风险收益率99%上行VaR和固定信用利差冲击，美元资产统一使用美国国债10Y并加入USD/CNY不利变动，默认未对冲。

碳价历史文件可放在被Git忽略的`data_sources/碳排放价格.xls[x]`或项目根目录。程序按日期及价格、收盘价、成交价等表头别名读取，以Excel单一价格序列的历史日收益率左尾1%统一代理重庆配额、CCER等全部碳资产并计算金额VaR。风险页将股票指数、中国国债10Y、美国国债10Y、USD/CNY及碳价的90%/95%/99%历史VaR集中列示，单位分别保持百分比或bp；全部美元利率资产统一使用美国国债10Y VaR，不再按剩余期限匹配美债期限。页面只保留300项逐资产明细，不展示口径不同的产品聚合表，并生成`全资产VaR明细.xlsx`下载文件。全组合VaR是逐项线性求和，日报金额是敞口代理而非实时公允市值；结果不是正式监管VaR或损失预测，未完整覆盖凸性、提前偿还、流动性和违约风险。

压力测试取各FOF最新估值表披露的底层市值，采用固定系数：股票指增对应指数1.0，股票中性贴水1.0，股票对冲指数0.5加贴水0.5，CTA/商品南华商品1.0；其他策略不强行估算。没有直接期货的股票标签统一使用IM贴水代理。六个固定情景及完整限制详见 [CALCULATION_METHOD.md](CALCULATION_METHOD.md#风控页面指数var股指期货贴水与压力测试)。

Wind缓存白名单包括中证1000、中证500、沪深300、中证2000、中证全指、中证A500、中证红利、国证2000及南华商品指数。股票二级标签映射对应指数，CTA/商品映射南华商品指数；宏观、多策略等无适用基准时不计算Alpha。顶层FOF继续以中证1000计算Alpha/Beta。

估值表解析和事件判断是辅助核算工具，不替代管理人对账单、交易确认书或托管银行流水。
## 底层资产多头敞口

网页顶部“底层分析”读取项目根目录 `底层资产` 中的底层产品估值表，展示股票市值、股指期货多空名义市值及多头敞口。公式为 `股票市值 + 股指期货多头名义市值 - 股指期货空头名义市值`；股票取 `1102` 汇总科目，期货只取“股指期货初始合约价值”汇总科目，排除冲销、估值增值和合约叶子行，避免重复计算。原文件只读，解析失败不影响主页面。
## 底层资产多头敞口

网页顶部“底层分析”读取项目根目录 `底层资产` 中的底层产品估值表，可按文件中实际存在的估值日期筛选当天全部底层，默认最新日期。结果先按关联FOF排序，同一FOF内按多头敞口占净资产比例从高到低排列。多头敞口为 `股票市值 + 股指期货多头名义市值 - 股指期货空头名义市值`。股票取 `1102` 汇总科目；期货按名称读取“股指期货初始合约价值”汇总科目，兼容 `3102` 衍生工具和 `3201` 套期工具等模板，并排除冲销、估值增值和合约叶子行。原始文件保持只读；`products` 扫描按附件内容SHA-256去重，同一内容只参与一次计算。
网页标题下显示本次 `index.html` 的生成更新时间。指数同期表现列示中证1000、中证500、沪深300和中证2000；无数据库行情时显示“暂无行情”，行情最新日超过10天时显示过期提示，不用旧值冒充当前行情。南华商品指数仅供底层CTA标签基准及风控内部计算，不在顶部同期表现展示。
