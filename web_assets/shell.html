项目说明

计算口径

所有产品期末资产：17只顶层产品在结束日期前最近估值的资产净值之和，仅由结束日期决定。

区间收益：仅汇总数据完整且可计算产品，公式为期末资产－期初资产－申购＋赎回＋现金分红。

XIRR年化收益率：以期初资产、台账申赎、现金分红和期末资产构造资金现金流，属于资金加权口径。

净值年化收益率：按（期末累计净值÷期初累计净值）^(365÷实际天数)－1计算。

年化波动率：相邻真实估值点的累计净值变化先按实际间隔天数换算为日对数收益，再按天数加权并以365天年化；不补齐缺失交易日。

夏普率：年化对数收益扣除固定2%年化无风险利率后除以年化波动率。最大回撤按累计净值相对区间历史峰值的最大跌幅计算。

指数同期表现：中证1000（000852）、中证500（000905）、沪深300（000300）采用Wind Oracle数据库AIndexEODPrices表中的价格指数日收盘；日期无行情时向前取最近收盘，展示区间涨跌、CAGR年化收益率和最大回撤。

Alpha/Beta：仅顶层产品相对中证1000计算。产品相邻真实累计净值区间和指数同期区间均按实际日历天数换算日对数收益并按天数加权；Beta为加权协方差除以基准加权方差，年化Alpha基于固定2%无风险利率按CAPM计算。至少需要10个有效区间、跨度30天且基准方差非零。

风险指标仅用于17只顶层产品；净值年化和最大回撤至少需要2个估值点，波动率和夏普率至少需要3个估值点；砚博没有正式累计单位净值，不计算这些指标。

已计算产品：开始日期和结束日期均有估值表的产品数量／该组产品数量；若所选日期为非交易日，允许向前取最近估值表。

当前总投资额：组内顶层产品在《专户资金台账》余额表中的本金；砚博采用天玑13号最新估值表披露成本。

创新金融业务总部所有组（所有产品）：保持17只顶层产品完整口径。

FOF1证投组：不含中金财富私享1554号、盛乾同行5号、五矿证券FOF50号和FOF51号，并从天玑13号中穿透扣除砚博指增6号。

FOF2研究所组：盛乾同行5号、五矿证券FOF50号和FOF51号。

其他组：中金财富私享1554号加砚博指增6号。砚博的期末资产、期间收益和当前成本从天玑13号底层持仓取得。

代码指令

以下为README中的用户操作命令，均在项目目录PowerShell中运行：

python -m pip install -r requirements.txt\n\npython app.py organize\npython app.py benchmark\npython app.py build\npython app.py download\npython app.py download --latest-only\npython app.py run\npython app.py analyze\n\npython app.py refresh\npython app.py share\npython -m unittest discover -s tests -v

organize整理手工加入的估值表；benchmark更新三只指数的本地缓存；build只重建网页；refresh依次下载、整理并重建；share启动密码保护分享。
