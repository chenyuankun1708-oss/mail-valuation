# 独立 FOF 月报生成器

本目录与项目网页、`index.html`、分享服务和 GitHub 发布流程无关。脚本只读取本机的原始估值表和《专户资金台账》，单独生成 Excel 月报；不会生成或修改网页，也不会下载邮件、更新指数或启动分享服务。

## 使用方法

在项目目录的 PowerShell 中运行：

```powershell
python monthly_report/generate_report.py --month 2026-07
```

默认输出到：

```text
monthly_report/output/FOF月报_2026年07月.xlsx
```

投资总览也提供“报告出具”：输入任意截止日后，由本机网页服务调用同一生成器并下载 `FOF月报_YYYY-MM-DD.xlsx`。月度起点为上月月末，结束点为输入的实际截止日。网页接口需要通过 `python app.py run` 或 `python app.py share` 启动，静态文件模式不能生成报告。

也可以指定路径：

```powershell
python monthly_report/generate_report.py --month 2026-07 --output "D:\报表\FOF7月月报.xlsx"
```

## 口径

- 月度区间：上月最后一个日历日至本月最后一个日历日，估值边界向前取不晚于边界日的最近估值表。
- 2026 财年：固定为 2025-10-31 至 2026-10-31；生成财年内月份时，结束日取当月月末。
- 顶层 FOF 金额收益：`期末资产－期初资产－区间台账净申购＋现金分红`。当前台账没有单列分红时，分红按 0 处理。
- 顶层收益率：使用 Modified Dietz，区间申赎按距期末剩余天数加权；年化收益率按实际日历天数复利年化。
- 投资以来收益：从产品首笔台账投资/首个估值日起计算；“投资金额”为截至月末的台账累计净投资。
- 底层产品收益：估值表没有独立成交流水，因此按期初、期末可比持仓数量乘价格变化估算；区间新增持仓以期末浮盈亏估算。退出持仓因缺少成交价不能确认退出收益，单列提示。
- 底层收益率：底层估算收益除以估算投入基数。它是分析估算值，不是管理人确认的交易损益，不要求与顶层 FOF 收益完全勾稽。
- 输出中的“数据边界与提示”工作表列出每只产品实际采用的估值日期、缺失边界和解析提示。

脚本复用本仓库已有的只读估值表与台账解析器，仅为避免重复维护几十种估值表格式；它不依赖网页计算、不调用 `app.py build`，输出也不会被网页读取。
